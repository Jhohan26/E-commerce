# Microservicio de Productos

## Grupo G - Productos

Microservicio encargado de la gestión del catálogo de productos para la plataforma de comercio electrónico distribuida.

## Responsabilidades

El microservicio permite:

- Registrar productos.
- Consultar productos.
- Consultar precios.
- Consultar categorías.
- Actualizar información del catálogo.

## Tecnologías

- Node.js
- Express
- MySQL
- HTML
- CSS
- JavaScript
